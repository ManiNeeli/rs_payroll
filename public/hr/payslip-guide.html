How to Create an Employee Payslip

Follow these steps in order every month. Steps 1–2 only need to be redone when something changes (a new hire, a raise, etc.) — steps 3–5 repeat every payroll cycle.

1. Make sure the employee has a Salary Structure

Go to Salary Structure. Select the employee, enter Basic, HRA, DA, and allowances, and save. Payroll cannot be calculated for anyone without this set.

2. Make sure attendance is being recorded

Check Attendance Management for the month. Payroll pro-rates pay based on how many working days the employee was marked present or on approved leave — days with no record count as unpaid (LOP).

3. Approve any pending leave

Check Leave Approvals. Approved leave is automatically excluded from LOP — pending or rejected leave is not, so approve requests before running payroll.

4. Run Payroll

Go to Run Payroll.

a.Enter the Month and Year for this payroll cycle.
b.Click Create Payroll Run. This sets up the run in "draft" status.
c.Click Calculate All Employees. This runs the payroll engine for every employee and shows a preview table with gross pay, PF, TDS, and net pay.
d.Review the numbers in the table. If anything looks wrong, fix the underlying Salary Structure or Attendance, then click Calculate All again — it will safely recalculate and overwrite the preview.

5. Wait for Admin approval

Once calculated, the run status changes to "processing." An Admin must review and approve it under Payroll Approval before employees can see their payslips. You cannot approve your own payroll run as HR — this is intentional, for accountability.

6. Employee sees the payslip

Once approved, the employee can log in, go to My Payslips, view the breakdown, and download it as a branded PDF. Nothing further is needed from HR at this point.

ProblemLikely Cause
Employee "Skipped" during Calculate AllThey don't have a Salary Structure yet — set one, then re-run.
Net pay looks too lowCheck their attendance — unmarked days count as unpaid leave (LOP).
